# AI 找片

当前改版：千问统一找片、联网和实时语音，一份百炼密钥；保留模糊搜片、精准直达及本地会话历史。

## 页面与手势

- 其他页面长按底栏中间入口仍可录音；AI 页底栏不拦截为录音，优先交给原液态玻璃按压/拖动交互，只有长按消息输入框才录音。
- AI 页保留原悬浮底栏，实际挂到 `AiPageContainer` 内，与对话共用一个移动、缩放和圆角裁切边界；不再单独下移、淡出。离开 AI 页时把原底栏还原到主界面，保持原来的导航行为。
- 容器注册可能发生在 Compose 的测量回调中，因此底栏换父容器统一通过主线程消息延后执行，不能在 `RelativeLayout.onMeasure` 遍历旧子视图列表时更换布局参数。连续切页合并为最新目标，销毁时取消待执行更新。
- 键盘弹出时底栏位置不变，由系统键盘覆盖；仅输入区避让键盘，键盘关闭后输入区回到底栏上方。
- 顶栏左侧「AI 找片」文字，右侧设置/新对话图标；直接使用窗口的系统栏 inset，避免多 Compose 宿主消费 inset 后标题顶到状态栏。
- 右滑露出左侧历史列表，当前页向右移动并缩小、保留一部分；左滑或点击当前页收回。返回键先收回抽屉，再返回首页。标题文字也可点击打开历史。
- 移动时直接改变卡片实际位置与尺寸，完整对话和底栏只在容器内部统一缩放，避免外层整屏矩形与内层圆角形成两套变换。拖动读取最新动画状态，轻点收回与横拖由同一套 Compose 手势协调。
- 历史背景带灰色，原生容器以同一圆角路径裁切背景、Compose 内容、底栏和遮罩；展开时保持卡片明亮。AI 页关闭返回首页的预测性返回动画。底栏去掉外围投影，保留液态玻璃折射、高光与按压形变。
- AI 页面实时绘制，已撤回 beta9 的整页快照。玻璃底栏采样画布使用 `matchParentSize`，不参与底栏高度测量，并在 Compose 与原生 Canvas 两处限定绘制范围，防止整页副本覆盖圆角卡片。
- 点击进入 AI 页立即关闭历史并恢复底栏，同时主动读取底栏高度；异常整屏高度不用于输入区避让。重复选择当前页不会再把该 Fragment 自己隐藏。
- 历史松手后的开合过渡为 360ms；对话和底栏由同一个父层变换，点击区域随之移动。玻璃采样只读取对话内容，不包含底栏本身，避免递归采样。`AiDrawer` 和 `AiNavigation` 日志记录容器、底栏挂载与实际尺寸。
- 长按对话在按下位置附近显示重命名/删除菜单，菜单避让系统栏与窗口边缘；用户重命名不会被后续聊天自动覆盖。
- 新对话按本地账号保存到私有文件，最多保存最近 60 个对话，每个最多 20 轮；不参与 WebDAV。旧 beta 未落盘的聊天无法恢复。
- 小圆球为原创矢量绘制，带柔和渐变、双眨眼、侧看、眯眼笑、单眼眨动与思考动作；后台停止动画，尊重系统关闭动画的设置。
- 影片卡片缩小，海报贴满左侧并随文字区高度裁切，长标题最多两行；不再显示首字占位封面。参考资料默认折叠，右侧箭头与文字居中，展开时转为向下。

## 一份百炼密钥

- 文字找片：千问 `qwen-plus`，官方 `https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation`。一个文本请求完成理解、联网与影片整理，关闭思考模式，返回 JSON 与联网来源；不再串行调用不同文本模型。
- 实时语音：阿里云百炼北京地域，`qwen-audio-3.1-asr-flash-streaming`，官方 WebSocket `wss://dashscope.aliyuncs.com/api-ws/v1/inference`。服务端新业务空间域名已推出，官方文档仍说明旧域名可使用。
- 找片、联网、语音共用北京地域百炼密钥，按各服务实际用量计费；直接搜片不调用文本模型，但云端识别仍消耗语音额度。
- 密钥用 Android Keystore AES-GCM 加密、按本地账号隔离，不写日志、不降级明文、不进入 WebDAV。复用 beta4 的百炼密钥槽；beta7 的字节密钥不会被误当成百炼密钥。
- AI 设置预设服务与模型，用户只填写一个密钥，无需模型 ID；提供独立的找片/语音连接测试，测试会产生少量用量。“开源许可”入口已移除，许可证资产保留。

## 实时语音

- 16 kHz 单声道 PCM，每 100 ms 采集一块。开始连接时缓存有限音频，收到 task-started 后才发送，避免漏掉开头。
- run-task → task-started → 二进制音频 + 中间文字 → finish-task → task-finished；最后一个结果返回前不关闭连接。
- 中间结果按 sentence_id 替换，跨句拼接，忽略心跳和其他任务的结果，不重复累加修正中的文字。
- 录音最多 30 秒，内存保存，不落盘。取消或退出前台立即停止采音并断开连接；不自动重试收费请求。
- 波形使用对数音量映射、平滑变化和独立的屏幕刷新，不等待语音转写事件。底部光晕渐入/渐出，上滑取消。
- 已移除 APK 的本地语音运行库依赖，不再下载本地识别模型。

## 搜索与推荐

- 语音中的明确「我想要看某片」「搜索某片」及简短裸片名优先直接搜索，不经过文本模型。对话只显示影片卡片，点击后后台匹配并进入影片；不显示可选片源列表、来源数量或第二次选择。连续点击正在处理的同一张卡片不会重启搜索。
- 片名、年份、国家、类型和演员线索一路传递给片源匹配。搜索返回字段不足时，后台补查详情；明确冲突的国家、年份、季数不放行。确认对应版本且详情存在剧集线路后进入原视频页播放；找不到则提示，不用同名错误版本兜底。
- 首页普通搜索保留原有模糊召回与候选选择；AI 卡片的直接进入不会使用模糊结果。
- 搜索回调计数在主线程交付后递增，防止后台计数先归零、界面还没收到其他同名结果就误跳。
- 条件/剧情等请求由千问推荐，豆瓣能匹配时补实际资料，不能匹配时不编造评分与海报。系列顺序、别名、近期信息及相关后续纠正都强制联网；复杂查询使用更充分的搜索策略。提示词要求简短回答，不机械拼接“系列名+第二季”。
- 卡片资料使用豆瓣完整影视搜索，并按版本条件核对，不能把只有五条的联想结果当成完整目录。完整条目不可用时保留搜索结果的真实海报；仍无匹配时，最多并行两次从符合版本约束的片源详情补资料，不伪标豆瓣评分。
- 涉及系列核实时，模型给出的正式片名还需通过目录核对；无来源或目录未核实时不自动跳转，不把模型自报 confirmed 当事实。目录失败时保留澄清路径，不额外调用第二个文本模型。
- 搜索关键词和候选标题统一清除书名号、外层引号和 Markdown 装饰；保留真正的季数、数字等作品身份信息。
- UI 搜索超时后，迟到结果真正收齐仍通知完成，避免漏掉自动跳转。`AiFlow` / `AiSearch` 日志区分模型请求、搜索与跳转耗时。
- AI 每次发送最近 6 轮上下文；不读取观看历史。编辑语音文字、新语音或选择新对话都会使旧核对结果失效，避免意外调用 AI。

## 已做检查与待验收

- release 编译检查；云端协议的本地模拟测试覆盖鉴权头、启动/音频/结束顺序、修正结果合并、心跳忽略、401、取消后禁止发送。
- 「薯克的救赎」片段召回与相似度排序、本地直搜分流已检查。
- 版本匹配回归覆盖美国/英国/中国同名作品、不同年份/季数、电影与电视剧及缺失字段；实查豆瓣能返回美版第十一季海报，未返回美版第一季时不使用英版顶替。
- 当前没有百炼密钥与连接的安卓设备，真实云端识别准确率、端到端延迟和触摸动效需真机验收，不能用模拟结果代替。

## 云端续播

- 当前播放器已有有效片源且云端是同集/同电影时，保留当前线路、解码器与播放页面，仅跳到云端进度；允许前跳和后跳。
- 真正换集或当前播放器尚未就绪时保留加载流程。识别同集优先使用相同集名、相同地址或普通数字集名，避免把不同源的列表序号直接当成相同集数。
- 接受云端进度会更新同步版本并作废此前排队的本机写入，防止旧进度覆盖新选择。
