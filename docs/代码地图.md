# 代码地图

## 源码结构

`app/build.gradle` 的 sourceSets 把 **mobile 目录作为 java/res 源码目录**合并进构建：

```
app/src/main/     → 主源码 + 主 AndroidManifest（实际生效的 manifest）
app/src/mobile/   → 手机端 UI（java + res，通过 sourceSets 合并）
app/src/leanback/ → 电视端（当前不构建）
```

**`app/src/mobile/AndroidManifest.xml` 不参与构建合并**——新增 Activity/Service 必须注册到 `app/src/main/AndroidManifest.xml`，否则运行时 `ActivityNotFoundException`。

只有 `release` 一个 buildType（`debug` 是 Gradle 隐式提供的），**没有 productFlavors**。上游 XMBOX 的 `assembleMobileArm64_v8aRelease` 那套 flavor 任务在本项目里早已不存在，见到引用它们的脚本或文档一律视为过时。
